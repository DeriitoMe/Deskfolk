# Deskfolk 语言切换

2026-10-24，Asia/Tokyo。本次仅更新本机，当前体验语言为 English。

## 交互

设置页顶部新增语言卡片，保留现有浅绿色视觉风格。提供三个按钮：

| 选项 | 行为 |
| --- | --- |
| 跟随系统 / System default | 启动时读取 Electron 系统语言；中文语言区域使用简体中文，其余使用英文 |
| 简体中文 | 明确选择中文，与系统语言无关 |
| English | 明确选择英文，与系统语言无关 |

选项使用各自的语言名称，方便切回。点击后自动保存，立即更新所有已打开的窗口和下一次打开的托盘菜单。卡片下显示当前实际语言；保存失败会显示错误并保留原选择。现有配置缺少 language 时采用 system，非法值不会覆盖当前选择。

## 英文范围

已覆盖设置、托盘、项目面板、状态标签、气泡、额度木牌、晨报的应用提示、按钮、可访问性标签和日期时间格式。外部通知正文、项目名、目录、晨报新闻标题与技能名称保持原内容。

英文使用简短的应用用语，如 Companion settings、Projects、Do not disturb。气泡保留角色口吻，如 “Saki, back to work.” 和 “We can rest now…”。英文气泡使用单独的字号与单词换行规则；400 像素窄窗口下连接状态可换行。

原角色录音不变。音频通过稳定事件身份匹配，显示中的气泡换语言时只更新文字，不重播声音、不重新计时。晨报换语言保留同一条已选内容，不消耗下一条新闻。

额度数字的含义保持现有规则：Codex 为五小时剩余比例，Claude Code 的 Current session 为已用比例。不可用、读取中和等待刷新分别显示，不补造比例。

## 实现与扩展

- `shared/i18n.ts`：支持语言、系统语言解析、英文目录与占位符。
- `renderer/i18n.ts`：窗口语言状态、静态文字和可访问性标签更新。
- `shared/event-copy.ts`：本地化事件文案与稳定音频身份。
- `shared/quota-copy.ts`：按已核实额度格式化标签。
- `preferences.language`：`system`、`zh-CN` 或 `en`，沿用原用户数据目录与 appId。

目录以原始应用文案作为键。新增语言时扩充类型、选项、翻译目录和语言解析，再补齐静态目录覆盖、占位符与真实窗口切换验收。语言切换本身不调用翻译服务。
