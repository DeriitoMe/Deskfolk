# 南宫羽像素 Q 版：结构与画法分析

状态：**分析完成，尚未据此重画若叶睦。** 本文依据用户提供的整页截图及其中站立、表情、动作、灰度小人局部。截图经过显示缩放，下面的比例是目测区间；无法从它可靠推断原始画布尺寸、精确色号、每格像素尺寸或实际调色板数量。

## 1. 先看她为什么是“小人”，而不是一个带脸的头

最有用的参照是页面第一行的站立小人，以及第三格的灰度版本。把颜色和角色装饰暂时放下，仍能辨出五段连续的人体结构：**发冠 → 脸 → 肩与上臂 → 收拢的衣身/裙摆 → 两条落地的腿。** 头发在脸两侧收进去，给肩膀留出可见空间；双臂从肩两侧斜伸，手的位置与身体轮廓分开；裙下两腿并不合成一根柱子。腿很短，但有明确的左右边界和脚尖。灰度格里这一点仍成立，说明读图并非依赖红绿装饰。

旧稿的根本问题是只提取到“头大、身小、格数少”，没有提取到这些连接点。发型被画成连续的圆顶，后发垂下来把肩和手框成暗块；脸是空白大矩形，衣身也是单一深色块。哪怕空白脸、裙子和腿各自存在，整体仍容易被读成有脸的毛团。

## 2. 比例：紧凑，不等于把身体挤掉

下表以**第一行站立小人的可见主体**估计。装饰、翘出的发梢会使边界有几像素误差；数值应作为构图范围，不是描摹尺寸。

| 关系 | 截图中可观察到的范围 | 起作用的原因 |
|---|---:|---|
| 头部高度 / 全身高度 | 约 60–65% | 头是焦点，但剩余约 35–40% 足够让肩、手、衣身、腿分层。 |
| 发型最宽处 / 身体含手宽度 | 约 1.7–2.0 倍 | 大头小身成立；手向两侧伸出，身体没有缩成一条线。 |
| 露出脸宽 / 发型最宽处 | 约一半 | 脸在头发中形成清楚的浅色窗口，同时保留不对称的发型轮廓。 |
| 脸的形状 | 宽于高的阶梯状圆角矩形 | 两颊和下颌有转折，顶部被不同高度的刘海压住，并非整齐的横切口。 |
| 下颌到脚底 | 约全身 35–40% | 这段区域实际包含衣领、躯干、手、裙摆和两脚，不能只画一块深色梯形。 |

截图中的像素块边界受缩放和压缩影响。下一次不能先规定“必须 32×32”再删掉五官或人体；应先保证这些结构在目标显示尺寸下可辨认，再定原生格数。

## 3. 外轮廓：不规则的发型与清楚的负空间

发冠是低弧线，但左右并不镜像：顶部有一组浅色头饰，侧边有横向外伸的红色发束/配件，下面又收回到脸颊。轮廓呈**外伸—内收—再外伸**的节奏，不是一条从头顶连续画到底部的半圆。额发也不是平均排列的齿；一大组主发流占优势，其余短发束只是修饰。

脸旁头发与袖子之间留有空隙。这样衣袖从肩部出去的方向能被看见，手也不会被误读为发梢。裙摆两侧有转角，裙摆与腿之间有空隙，两腿之间还有一条窄缝。即使将人物填为纯色，头、肩、双手、双脚的大致分区仍应成立。

## 4. 视角与表情：轻微侧向，不是严格正面模板

这是两眼都可见的轻微三分之四角度。两侧额发、侧发、露出脸的宽度并不完全相等；双眼及眼周留白也有轻微差异。身体进一步强化了这个方向：肩、手和脚的形状/位置并非左右翻转。站立、抬腿、举手几个格子延续同一头部身份，却用不同肢体位置改变重心。

五官的“像人”来自层级：暗色上眼缘、白色眼部区、暖色虹膜各占一小组相连像素；两眼虽然很省格，但不是两个孤立的棕色点。脸下部很克制，嘴鼻只是极小的辅助标记。转换到无口的若叶睦时，可以取消嘴，但**眼睛与额发、颊线的相对位置仍需提供表情与朝向**；单把一只眼缩成一格不能代替侧脸结构。

## 5. 色块与描边：大块定形，小块点睛

- 最暗的发色和外轮廓把头、脸、手及服装分开。描边不是均匀黑框：转角和重叠处更重，受光边缘可用较浅色衔接。
- 脸是画面最大的浅色焦点，眼白和暖色虹膜形成第二层对比。红、青绿等高饱和色集中在发饰、衣领和细小服装特征处，没有均匀撒满全身。
- 头发先按几块明确的发束画明暗，再给极少量亮点。灰度版本保留人物识别度，说明明暗分区比颜色本身更关键。
- 像素边界多用有节奏的阶梯，不以细碎单格噪点去“补细节”。单个高亮像素只放在眼睛、发饰等值得注视的位置。

对若叶睦的浅绿发色，必须另设足够深的薄荷绿阴影和局部轮廓，隔开浅绿发与奶白皮肤；单纯提高绿色饱和度只会让一整团头发更显眼。深蓝制服要有可辨的白色水手领、袖口和裙摆层次，避免在深色桌面上合成暗块。

## 6. 同一人物的多格如何保持协调

第一行的站姿、灰度格、头像格，以及第二行的动作格，反复沿用**头发外轮廓、顶端配件位置、脸在头中的窗口、衣领色块**。变化集中在眼睛、手臂道具、腿的朝向和重心。这是“少格数却生动”的原因：固定身份结构稳定，活动部分有充分的动作幅度；每个变化都仍读得出头、脸、身、手脚。

灰度格是关键检查：它去掉部分色彩信息后，发型、脸部窗口和肢体仍可辨。头像格则显示，缩小到只有头部时，不规则的侧发与眉眼关系已足以保留身份。二者一起证明，辨识度首先落在**轮廓、负空间与明暗安排**上。

## 7. 对已有若叶睦稿的错误诊断

| 旧稿问题 | 在参照中缺失了什么 | 下次必须怎样检查 |
|---|---|---|
| 绿色圆顶像头盔 | 侧边外伸与内收、主次发束、脸旁负空间 | 关掉内部纹理，只看轮廓；不能读成单一半圆。 |
| 脸宽却空，像贴在发上的面板 | 额发、眼睛、颊线之间的三段关系 | 两眼有眼缘与瞳色，额发的结束点要引导视线到眼睛。 |
| 用缩小一只眼表示侧脸 | 脸、发、肩与脚的共同偏转 | 只看剪影和明暗也要能辨出轻微转向。 |
| 深蓝衣身与手腿连成一块 | 独立袖子、手、衣领、裙摆、左右腿 | 在浅色和深色背景下逐一指出各部分边界。 |
| 强制压格后丢失人体 | 先设计结构、后确定原生分辨率的顺序 | 压格后若肩、手或腿不可读，就回到结构稿，不能用更多花纹补救。 |

## 8. 从参照反推的实际作画顺序

1. **先定动作线和重心**：决定头的轻微朝向、肩线、哪只脚承重。参考的站姿和抬腿格共用头部结构，但腿与手的位置改变后，整个人的重心也随之变化。不能先画完正面对称头，再把眼睛挪一格冒充侧向。
2. **只画整个人的外轮廓**：把不规则发冠、外伸侧发、肩袖、裙摆和两条腿一次排进同一小画幅。头发在脸颊附近收窄，让身体从下方露出。此时不画眼睛与衣服花纹。
3. **挖出脸的浅色窗口**：先确定眉眼、左右脸颊和下颌的边界，再让额发盖住上缘。脸不是随意贴在发团上；它的位置决定发束何处结束、肩线从何处开始。
4. **建立衣领、袖子、手、腰和腿**：这些部分先用明暗相邻的大色块区分，之后才加角色的具体服装颜色。参考图胸前一小组亮色像素虽然少，却把手臂和躯干拆开；此处的对比必须保留。
5. **分两级补发束与表情**：先画决定轮廓/方向的主发束，再补少量颜色与高光；先画眼缘和眼白的位置，再画虹膜。装饰色只落在确定的结构节点，不拿散点填满空白。
6. **同尺寸检查不同底色**：最终评价的是正常桌面尺寸里的小人。若五官只能在 8 倍图上读出、手脚在深色背景消失，说明结构或明暗尚未完成，不能当作“简洁风格”接受。

可以把前三步理解为“人形能否成立”的关卡，后面的发色和服饰只是身份细化。参考图第三格的灰度小人就是这套顺序的旁证：颜色去掉后，前四步建立的形状仍然可读。

## 9. 下一次画图前的结构验收顺序

1. **纯剪影**：只允许头、肩、双臂、衣身、两腿五类形状。遮住颜色仍须能看出站着的人；头发侧边不能把手封死。
2. **灰度分区**：脸为最清楚的浅块；头发、衣领、裙装彼此有明确边界。若变灰后只剩“大头、黑身”，停下修改。
3. **轻微侧向**：脸颊轮廓、两眼在脸中的位置、主刘海、肩与脚朝同一个方向偏转。两眼仍可见。
4. **角色转译**：再加若叶睦的浅绿主发流与长侧发、琥珀眼、无口、水手领与淡紫领结；发束数量由轮廓需要决定，不为“还原长发”而遮住四肢。
5. **实际尺寸复查**：在浅、深桌面背景及目标 160–200 物理像素范围内看；不靠放大图解释手脚位置。若失败，修改轮廓或格数。

这些是截图足以支持的**可操作规律**。它尚不足以证明已掌握原作者每个像素的摆放方法；若获得未经缩放的原始立绘像素文件，才能准确核对原生格数、调色板与描边厚度。本阶段到分析为止，不制作新模型或动作。
