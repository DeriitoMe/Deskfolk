# V42 鼠标跟随与工作状态修补

本次直接修补当前 V42，继续使用已确认的 Blender 模型和最新后领悬吊姿态。

## 修改

- 单项目工作恢复与待机相同的头部、身体立体跟随：轻微转向、倾斜和探身。眼睛原有移动范围和阻尼保留。
- 修正头部及身体上下转向的符号，使鼠标在下方时向下看、在上方时向上看。
- 全力工作、浇水、小憩、拖拽等动作继续由各自动作控制姿态。
- 启动时先监听工作状态，再读取初始信息；已有的新工作状态不会被旧的待机信息覆盖。
- 原生异步询问按实际调用 ID、轮次和问题索引接入。收到询问仅表示待回答，全部问题的原生回复到达后才恢复对应状态。
