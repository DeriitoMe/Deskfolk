# 超级工作气泡（2026-10-14）

## 表现与触发

- 普通工作沿用“祥，工作”和原工作音效。
- 进入超级工作状态时，独立显示九个全角感叹号 `！！！！！！！！！`，播放用户提供的 1.5 秒声音。
- 依据现有聚合器确认的不同工作项目数判断进入，沿用项目身份和目录统计规则。同项目多个会话不增加不同项目数。
- 从不足两个工作项目进入至少两个时提示一次；持续工作、第三个项目开始和进度消息保持当前超级工作表现。
- 减少到不足两个项目时取消待播超级提示、隐藏其气泡并停音；之后再次进入可以再次提示。
- 问题提醒、庆祝、失败反馈、点按和拖拽仍沿用现有优先级。超级提示等待表现允许时播放，等待过程中若退出超级状态则取消。
- 静音或关闭通知时丢弃该提示。历史恢复和启动回放只恢复状态，不播放进入提示。

- `renderer/main.ts`：新增专属音效映射、独立气泡类型及进入提示的展示，阻止普通开始气泡覆盖超级提示。
- `shared/work-bubble.ts`：专属文案和基于聚合状态的单次进入门控。
