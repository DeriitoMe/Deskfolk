## 消息与提醒规则

气泡参考用户图一：近白底、不规则椭圆、深绿色细边与递减思考圆点。根据 Windows 缩放校正显示尺寸，默认气泡整体约 264 物理像素宽，避免系统 150% 缩放把气泡放大成桌宠的数倍。

只显示以下事件的气泡：

| 事件 | 气泡与处理 |
| --- | --- |
| 原生 Codex 待询问 | 保持提醒，按钮「打开 Codex」 |
| 原生问题已解决／新用户输入 | 收起提醒，恢复对应工作状态 |
| 一轮结束 | 空闲时显示「结束了......」，随后按原设置自动隐藏 |
| 明确阶段完成／任务完成 | 显示实际完成消息 |
| 普通 info、开始工作、工具进度 | 不弹出桌面气泡 |
| 未确认存在原生问题的 needs_input、旧宠物问题 | 不触发询问状态或气泡 |

源码未发现「有需要你处理的信息」这一字面文本，但原实现会将普通信息以及无内容的 PermissionRequest 事件展示成互动提醒。真实记录中存在大量此类权限事件；自动审批事件本身不能证明用户仍需操作。本轮移除该 Hook，拦截无明确用途的互动提醒，保留由原生询问工具产生的提醒。工具仍可用 `native_question: true` 明确标记已经发布到 Codex 原生面板的真实问题。

移除了可运行的宠物答题窗口、preload 答案 API、MCP ask/wait/resolve 工具。旧 `/questions` 接口返回 HTTP 410。旧源码文件仅保留作历史参考，不进入编译包。

本机确认的官方应用为 Windows 应用包 `OpenAI.Codex`，实际进程名为 `ChatGPT.exe`。按钮通过 Windows 窗口 API 恢复并置前该官方应用；未运行时通过其 AppsFolder 启动标识启动。**保留 Codex 当前所选聊天，不伪造问题，不发送答案，也不自动跳到另一个会话。**实测官方窗口激活成功。

本地插件已按 Codex 官方插件 CLI 更新为 `0.1.0+codex.20260926161638`；新聊天会加载新工具目录与技能。已经运行的旧 MCP 进程／旧聊天可能保留旧工具元数据，更新后的桌宠仍拒绝旧答题接口。

## 日常动作

| 动作 | 配置时长／规则 |
| --- | --- |
| 正常待机 | 30 秒 |
| 小憩 | 15 秒，450 帧源稿 |
| 正常待机 | 30 秒 |
| 浇水 | 15 秒，450 帧源稿 |
| 开心收尾 | 3.6 秒，108 帧源稿 |

点击命中宠物时立即取消小憩／浇水／其开心收尾，恢复普通待机；这次点击不会再播放护脸动作。移动形成拖拽时仍保留被拎起挣扎动作，松开后从待机重新计时 30 秒，不续播旧动作。其他情况下的触摸、Codex 工作和等待状态保持原逻辑。

浇水到开心去掉原来绕经中立姿势的 0.38 秒停顿；手、身体、眼睛和道具直接连续过渡，花朵与暖色在收尾开始后即渐入。

小憩增加独立 `sleep` 效果图层：深蓝色 Zzz，三枚错时出现的小字母，逐渐变大、向脸右上方飘动，并在接近头顶时淡出。图形由 Krita 生成与保存，时间轴由 Aseprite 整理。

### 绘画与帧数

- 两种形态各 **16 张**角度稿，共 32 张，角度间隔约 22.5°。
- 辅助原画由内置 imagegen 生成，输入参考与完整提示词保存于资源目录。
- Aseprite 中完成透明边缘清理、完整轮廓提取、脚部对齐、配准补间与光影修整；每形态 96 个旋转素材帧，另有 32 个收势素材帧。
- 成片源稿 `transform-30fps.aseprite` 为 **306 个独立时间轴帧**，按实际时间采样，不以 8 张图循环替代帧数。
- 33／33／34 毫秒帧时长循环，平均准确 30 FPS；实时日常动画目标 60 FPS，转场按 30 Hz 采样。
- 旋转稿与用户原图之间有专门收势补间；停稳后的主体确实使用用户提供的图二，未用生成稿替代原图。

### 尺寸与位置

默认 Q 版主体约 **157 × 195 物理像素**。图二主体去除游离透明噪点后的比例为 661:1338，归一稿 222 × 449 像素；华丽形态以 2 倍模型尺度显示，约 **193 × 390 物理像素**，比 V39 的约 165 × 321 更大。转身时抬手、飘发、裙摆会占用更宽空间，画布扩为 768 × 1152，并按完整旋转轮廓预留窗口范围。

修复 Windows DPI 取整造成的往返漂移：缩放窗口时保留脚部的屏幕坐标。打包版在本机 150% 缩放测试中，转场结束后窗口位置准确恢复。
