# 左键点按：快速按压反馈（2026-10-07）

## 优化后的执行提示词

仅重做桌宠左键单击触摸动作。合法点击后立即快速低头下压，再抬起并轻微反弹归位，像可爱的按钮按压反馈。按压时使用现有><眼睛，整个过程为零点几秒，快速连续点击要逐次立即响应，不排队、不延长卡住。保留模型造型、其他动作、拖拽和状态入口；保留修改前回退点。

## 实现

- 总长0.38秒：约0.075秒压到底、0.02秒短停，0.145秒释放，随后小反弹并归位。
- 头、头发和眼睛使用已有头部控制器刚体下移，最大0.13世界单位，默认显示尺寸下约5–6物理像素；不改变模型各部件缩放。
- 沿用现有><图稿和颜色。旧护脸、双臂甩动及汗滴不参与新的触摸动作。
- 每个有效左键单击都强制重启touch。压着时再次点按，会有约0.025秒的小释放，再迅速压下，形成独立脉冲。
- 统一缩短触摸入场混合至0.025秒，减少动态效果模式保留实际按压时间但减小幅度；30FPS仍能呈现完整动作。
- 点击完成后保留原生拖拽累计位置复位，再保持鼠标接收，允许静止指针反复点击。触摸期间在上次真实命中点周围4DIP保持局部命中；补偿点击不逐次移动锚点，真实拖拽、取消、模型替换或触摸结束后清理。
- 原有拖拽阈值、右键和小憩/浇水首次点击打断规则保留；本轮仅涉及点按反馈相关代码。
