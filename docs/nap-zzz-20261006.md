# 小憩 Zzz 可见度调整

日期：2026-10-06。基线提交：`fb40c57`。应用版本：`0.1.0`。

## 修改

`renderer/three-rig.ts` 的小憩文字字号从 `13 + 18u` 改为 `24 + 32u` 像素，即 24–56 像素，约为原来的 1.8 倍。按 220 像素桌面画布显示时，字号由约 5.6–13.3 像素增为 10.3–24.1 像素。

保留三字母数量、深蓝色、现有字重、2.7 秒飘动周期、路径和渐隐公式。模型、表情、15 秒小憩时长、30 秒待机节奏和 Codex 状态逻辑未调整。

## 验证

- 生产构建通过。
- 使用真实 3D 渲染器，在独立隐藏 Electron 预览中分别采样 0.6、1.35、2.1 秒；文字边界均位于 512 × 512 画布内。
- 相同预览方法、60 FPS 帧率上限，采集稳定后的约 2 秒窗口：修改前约 60.005 FPS，修改后约 60.005 FPS，实际 ASAR 包约 60.003 FPS。这是隔离预览测量，非所有桌面负载下的性能保证。
- 更新包仅替换安装包中的 `out/renderer`，其他包内文件校验一致，包括状态逻辑和模型素材。
- 已应用到现有本机安装并启动，应用窗口响应正常，安装包 SHA-256 与验证包一致。

对比预览：`docs/images/nap-zzz-20261006.png`，同一姿态和时间，在浅色与深色背景下按 220 像素桌面画布尺寸展示。
