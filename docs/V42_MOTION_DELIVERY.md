# V42 动作与状态修订

本轮基于 V41 实时 Three.js 桌宠及已确认的 V05 造型。运行文件为 `release/v42/win-unpacked/Liquid Glass Pet.exe`；安装包为 `release/v42/Liquid Glass Pet Setup 0.1.0.exe`。

当前拖拽姿态已按前四张蔚蓝档案参考调整为近正面的低头悬吊，记录及新源稿见 [后领悬吊修补](V42_COLLAR_LIFT_PATCH.md)。此前的小角度调整见 [拖拽角度修补](V42_DRAG_ANGLE_PATCH.md)。下方源稿和动作总览保留初次 V42 的评审记录。

头身鼠标跟随和工作状态接入的后续修补见 [鼠标跟随与工作状态](V42_GAZE_WORK_PATCH.md)。

## 修改内容

### 形态

- 当前仅启用简约 Q 版。设置中的高清柔光和旋转变身处于停用状态，托盘变身入口不可用。
- 启动读取旧高清配置、保存高清配置、直接收到变身消息时，都保持 Q 版。
- `shared/runtime-policy.ts` 集中记录策略。原变身实现、高清图片、转场图集及 V41 目录全部保留；包内原模型和华丽资源已逐项比对 V41 SHA-256。

### 拖拽与点击

- 悬吊支点设在后衣领处，身体转向侧前方、向前俯身，头部反向调整角度；部件采用刚体旋转和平移，保持原始比例。
- 水平方向惯性叠加在屏幕坐标的旋转上：向左拖向右倾，向右拖向左倾；停止移动后按时间阻尼回正。
- 4.6 秒循环：先放松；1.35–1.95 秒和 2.03–2.63 秒各反抗一次；随后恢复放松。两次反抗期间双手、双脚同时参与，眼睛平滑切换为 `><`。
- 释放使用 0.65 秒恢复段，包含轻微落地缓冲；动作结束后返回当前实际状态。
- 点击和挣扎共用 Krita 导出的左右眼图层。颜色沿用常态眼睛 `#b87925 → #ca8b30`；192×256 眼睛画布中线宽为 20，常态眼睛宽 70，表情上下跨度为 102。旧点击线宽 12、跨度 60。

### 工作与暂停

- 单项目工作恢复眼睛的鼠标跟随；身体保持工作姿态。全力工作、小憩、浇水、疑惑、点击、拖拽不接收新的视线跟随。
- 代码式流光采用错开的字符列、不同滚动速度和稳定种子变化。速度为 82、99、116 眼睛画布像素/秒，较 V41 约 548 像素/秒的主光带放慢；全部效果裁切在金色眼睛轮廓内。
- 实际日志存在 `turn_aborted` / `reason: interrupted`，原日志观察器能够映射为暂停。
- 本次发现的残留原因：无会话标识的工具通知会产生额外的 `codex` 工作记录。现在无归属通知不能建立任务，遗留的合成工作记录会清理，未开始的工具进度也不能凭空创建工作状态。
- 实机还发现会话日志首行约 20 KB，超过原先 16 KB 的固定读取上限，导致日志被跳过。现在分块读取完整元数据首行，再核实会话标识，能够正确恢复正在工作的任务并接收其后续暂停记录。
- 继续沿用真实任务开始、结束、暂停日志和已有 Hook；迟到进度不能复活已经结束的回合。暂停一个项目不会结束其他项目。没有添加按静默时长推断完成的超时规则。

### 动作衔接

- 道具着色器、纹理与几何在首次显示前预热。
- Q 版原生窗口预留现有 512 像素渲染画布所需宽度，待机切到浇水不再改变窗口尺寸；仍按可见内容控制屏幕边缘拖动。
- 浇水先转身、抬手，再淡入洒水壶和花盆，随后出水；取消整套道具从零缩放的过程。壶体保持在身体前方，避免准备时埋入裙子。
- 视线按动作权重收回，点击/挣扎/开心眼睛连续淡入淡出。中断小憩、浇水时立即切换待机状态，并从当前姿势恢复。
- 保留原有 30 秒待机间隔、15 秒小憩、15 秒浇水和浇水后的开心段。

- 状态与日志测试 12 项通过，覆盖长元数据首行、真实日志格式、分段写入、暂停、迟到工具事件、不同项目与无超时退出。
- 实际打包代码通过启动、Q 版限制、变身阻断、设置入口、单/多项目暂停路径测试。
- 最终运行版本已经从本次真实 Codex 日志恢复 1 个工作的项目，读取到原生暂停记录；不存在合成的 `codex` 工作项。证据见 `verification/actual-lifecycle.json` 与 `verification/live-runtime.json`。
- 拖拽循环检测到两次反抗峰值；左右惯性方向正确；所有控制部件缩放始终为 1。

- 实际输入测试通过：点击/拖拽打断小憩和浇水，释放回到待机，重新计算 30 秒间隔。
- Krita 源稿含 2 个独立图层；Aseprite 文件全部重新打开验证帧数；Blender 文件已重新打开检查 13 个控制节点、788 帧及部件比例，并保留全部依赖图片。

详细结果在 `v42-motion/verification/` 与 `v42-motion/preview/` 中。`preview/V42-overview.png` 为动作总览，`preview/drag.gif` 与 `preview/water-entry.gif` 可直接查看动作。

## 回退

1. 从 V42 托盘选择“退出”。
2. 运行 `release/v41/win-unpacked/Liquid Glass Pet.exe`，即可恢复旧版程序与原资源。
3. 本轮修改前完整代码副本、V41 `app.asar`、设置快照位于 `.cache/v42-rollback-20260928-014959/`；如需源码回退，将其中对应的 `renderer`、`electron`、`shared` 等文件复制回项目。
4. 设置快照分别位于该目录的 `user-data/` 和 `before-runtime-switch/`。只在确实要恢复旧设置时复制偏好与位置文件；通常直接启动 V41 即可。不要把历史工作状态快照当作当前任务状态恢复。

本次没有删除华丽素材、修改原 V05 Blender 文件，或覆盖 V41 唯一源稿。
