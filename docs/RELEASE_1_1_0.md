# Deskfolk v1.1.0

![Deskfolk v1.1.0：红色贝雷帽装](https://raw.githubusercontent.com/DeriitoMe/Deskfolk/v1.1.0/docs/images/promo/deskfolk-beret-outfit.png)

这一版给若叶睦换上了**新衣服**，也加了英文界面和几种新的日常动作。

## 新服装：红色贝雷帽装

在设置的“外观”里选“服装”，可以在**校服**和**红色贝雷帽装**之间一键切换，不用重启。

- 戴在后脑的红色贝雷帽，黑色短披肩配金色饰边，红色马甲和金扣，米白领巾和绿色胸针，黑色燕尾外套，红色短裙，深灰长袜和红色短靴。
- 衣服按她原来的体型建模，头身比和动作都不变：浇水、看报纸、弹吉他、被拎起来晃，衣服都跟着动。
- 默认仍是校服；升级后原来的设置不受影响。

## 英文界面

设置里新增“语言”：**跟随系统 / 简体中文 / English**，立即生效，重启后保留。托盘菜单、设置、当前项目面板、气泡提醒和额度木牌都会切换语言；项目名称和外部内容保持原样。

## 新的日常动作

- **弹吉他**：闲着的时候，她会抱起粉色七弦吉他端详一会儿。打盹、浇水、弹吉他轮流出现。
- **彩蛋动作**：弹吉他的时候偶尔会有一个小彩蛋。
- **新的庆祝**：任务完成时，她会抱胸、屈膝、跳起来拉响两只礼花筒，彩纸慢慢飘落，落地后轻轻摇摆。
- **看晨报**：如果本机装有 Skills Morning Brief（晨报），启动后约 15 秒她会翻开一份立体的晨报逐行阅读，看完一页提一条新消息。托盘菜单里也可以随时选“看晨报”。没有安装晨报时不会出现这个动作。

## 下载

下载下方 **Assets** 里的 `Deskfolk-Setup-1.1.0.exe`（Windows x64）。安装前先退出正在运行的 Deskfolk，原来的设置、通知记录和桌面位置都会保留。安装包没有数字签名，可以用 `SHA256SUMS.txt` 核对。

Codex、Claude Code 和 DeepSeek Harness 的接入方式与 v1.0.1 相同。

## 已知限制

- 目前只有 Windows x64 安装包，角色只有若叶睦。
- 安装包没有数字签名。
- DeepSeek Harness 没有提供额度数据，右键木牌显示“暂不可用”。

## English

Deskfolk v1.1.0 brings Mutsumi a new outfit. In Settings › Appearance › Outfit you can switch between the school uniform and the new **crimson beret outfit** (beret, capelet, vest, tailcoat, skirt, stockings and boots), instantly and without restarting; every action works in both. Settings now offer **System / 简体中文 / English** for the whole interface, and the choice persists. She also gains new everyday moments: a guitar daydream while idle (with an occasional easter-egg move), a new jumping party-popper celebration when tasks finish, and, if Skills Morning Brief is installed, reading the brief shortly after start-up or from the tray. Download `Deskfolk-Setup-1.1.0.exe` below; the installer is unsigned, so verify it with `SHA256SUMS.txt`.
